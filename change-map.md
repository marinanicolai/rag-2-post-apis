# Where a rule's behavior is written down

| Place | What it encodes | How to change it |
|---|---|---|
| `restrictions/<rule-id>.md` | The rule: frontmatter, explanation, user message | Edit directly |
| `restrictions/PACK.md` | Pack settings, ceiling, classification ladder | Edit only when the policy owner decides |
| `restrictions/tests.yaml` | Corpus run by `validate_pack.py`: `name`, `file` or `text`, `expect: allow/deny`, `rules: [...]` | Edit; keep names describing behavior |
| `samples/*.json`, `samples/files/*` | Request frames and files replayed by tests | Edit the content (for example add a valid marking) rather than the expectation when the sample should stay "clean" |
| `scripts/proxy_selftest.py` | `Case(name, request, expected_rule_or_None, note=...)`; `None` means allow. Tests find cases by the start of the name | Edit; keep the name prefix |
| `tests/test_client_hook.py`, `tests/test_client_proxy.py` | Hook and proxy behavior with exit codes and `deny_rule_id` | Update expectation and test name |
| `docs/risks.yaml` | Source of truth for the risk register: each risk's `rules:` and `evidence:` (`fixture`, `hook_file`, `hook_prompt`, `pytest`, `zscaler_probe`) | Edit; YAML indentation matters |
| `tests/test_risk_register.py` | Some hard-coded status strings per risk | Update when a risk's status legitimately changes |
| `scripts/zscaler_spec.py` | Mapping dict: one entry per rule id (`dictionary`, `source`, `build`, `notes`) | Add or update the entry |
| `tests/test_zscaler_spec.py` | Assertions such as which rule is logged rather than denied | Update when the posture changes |
| `docs/RISK_REGISTER.*`, `docs/evidence/risk-evidence.json` | Generated by `scripts/risk_register.py` | Regenerate only |
| `docs/ZSCALER_RULE_SPEC.*` | Generated by `scripts/zscaler_spec.py` | Regenerate only |

## Checks

| Command | Passes when |
|---|---|
| `python scripts/validate_pack.py` | Pack loads and every corpus case passes |
| `python -m pytest tests -q` | No failures (skips and deprecation warnings are expected) |
| `python scripts/zscaler_spec.py` | Reports 0 unmapped rules and 0 marking literals in output |
| `python scripts/risk_register.py` | Every risk shows 0 in the fail column |
